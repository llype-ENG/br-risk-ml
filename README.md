# BR-Risk ML

O **BR-Risk ML** é um projeto de Ciência de Dados e Machine Learning desenvolvido para analisar padrões de acidentes nas rodovias brasileiras, identificar fatores associados à gravidade das ocorrências e explorar modelos preditivos capazes de auxiliar na compreensão e prevenção de acidentes de trânsito.

O projeto utiliza dados públicos disponibilizados pela Polícia Rodoviária Federal (PRF), abrangendo registros de acidentes entre 2017 e 2025.

### Objetivos

O desenvolvimento está dividido em duas etapas principais:

**1. Classificação da gravidade dos acidentes (Pós-acidente)**

Desenvolvimento de modelos de Machine Learning capazes de classificar acidentes em três categorias:

- Sem vítimas;
- Com vítimas feridas;
- Com vítimas fatais.

Serão avaliados diferentes algoritmos de classificação, considerando métricas como precisão, recall, F1-score e desempenho na identificação de acidentes fatais.

**2. Predição de risco de acidentes (Pré-acidente)**

Desenvolvimento futuro de modelos capazes de identificar condições e padrões associados ao risco de ocorrência de acidentes, buscando transformar dados históricos em informações úteis para análise preventiva.

### Tecnologias e métodos

### Fonte dos dados

Dados abertos de acidentes rodoviários disponibilizados pela Polícia Rodoviária Federal (PRF).
